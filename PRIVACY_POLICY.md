## Политика конфиденциальности WB AI Helper

Обновлено: 2 июля 2026 г.

WB AI Helper — это расширение для браузера для продавцов Wildberries.ru. Оно помогает продавцам создавать профессиональные ответы на отзывы покупателей. В качестве бэкенда расширения используется jocs.ru.

## Обработка данных

WB AI Helper может считывать данные на вкладках, соответствующих следующей URL-маске:

- https://seller.wildberries.ru/feedbacks/feedbacks-tab/not-answered/*

Данные отзыва передаются на бэкенд для генерации ответа. В состав этих данных входят:

- имя автора отзыва
- оценка
- причина обращения
- данные о товаре (название, URL, артикулы, цвет, размер)

## WB AI Helper хранит следующие данные локально в браузере пользователя:

- идентификатор пользователя, автоматически создаваемый при установке расширения
- результаты последних действий пользователя (сообщения от API, ошибки, информация), используемые для отображения на вкладке «История»
- URL бэкенда
- ключ API для доступа к бэкенду
- прочие настройки (язык и т. д.)

## Использование данных

WB AI Helper собирает:

- идентификатор пользователя (хранится и на бэкенде, и в расширении)
- данные отзыва (только на бэкенде)
- сгенерированные ответы (только на бэкенде)

Бэкенд передаёт данные отзыва AI-провайдеру в рамках процесса генерации ответа. WB AI Helper (включая бэкенд) не собирает, не передаёт и не хранит:

- историю посещений браузера, URL вкладок или любую другую активность в браузере
- файлы cookie
- учётные данные продавца или его личную/коммерческую информацию из Личного кабинета

WB AI Helper не использует рекламу, трекинг-пиксели, удалённое логирование или телеметрию.

## Передача и продажа данных

WB AI Helper не продаёт данные пользователей. WB AI Helper не использует и не передаёт данные пользователей для целей, не связанных с основной функциональностью расширения.

## Удалённый код

WB AI Helper не выполняет удалённый код. Код (минифицированный) расширения поставляется в составе опубликованного расширения.

## Контроль пользователя и удаление данных

Пользователи могут удалить сохранённые данные, удалив расширение из браузера. Также можно очистить хранилище расширения через настройки браузера или инструменты разработчика.

## Контакты

# WB AI Helper Privacy Policy

Last updated: July 2, 2026

WB AI Helper is a browser extension for Wildberries.ru sellers. It helps sellers create professional responses to user reviews. jocs.ru is used as the extension's backend.

## Data Handling

WB AI Helper can read data on tabs matching the following URL pattern:

- https://seller.wildberries.ru/feedbacks/feedbacks-tab/not-answered/*

The details of the review are transmitted to the backend to generate a response. These details include:

- reviewer name
- rating
- feedback reason
- product details (name, URL, vendor codes, color, size)

WB AI Helper stores the following data locally in the user's browser:

- user id, autogenerated when the extension is installed
- results of recent user actions (API messages, errors, info), used to display them in the History tab
- API URL
- API key to access the API endpoint
- other settings (language, etc.)

## How Data Is Used

WB AI Helper collects:

- user id (stored both on the backend and in the extension)
- details of a review (only on the backend)
- generated responses (only on the backend)

The backend transfers details of a review to an AI provider as part of the AI generation process.

WB AI Helper (and its backend) does not collect, transmit, or store:

- browsing history, active tab URLs, any browsing activity
- cookies
- seller account credentials or personal/business information

WB AI Helper does not use advertising, tracking pixels, remote logging, or telemetry.

## Data Sharing And Sale

WB AI Helper does not sell user data.

WB AI Helper does not use or transfer user data for purposes unrelated to the extension's core functionality.

## Remote Code

WB AI Helper does not execute remote code. Extension code (minified) is packaged with the published extension.

## User Control And Deletion

Users can delete stored data by uninstalling the extension from the browser. Users can also clear extension storage through browser settings or developer tools.
